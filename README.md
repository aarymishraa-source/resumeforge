# ResumeForge

A simple online resume builder. Fill in a form, watch a live preview update as you type, then download a real PDF.

## Features

- Live preview that updates instantly as you type
- Three different templates - Modern (blue accent), Classic (serif & traditional), Minimal (clean whitespace)
- Profile photo upload that shows up in both the preview and the PDF
- Save / load / edit / delete resumes (full CRUD on SQLite)
- Real PDF download from the backend using ReportLab
- Browser print support (works as a backup PDF option too)
- Mobile responsive layout - works on phones and tablets

## Tech Stack

- Backend: Python 3, Flask, SQLite, ReportLab
- Frontend: HTML5, CSS3, vanilla JavaScript (no frameworks)
- Database: SQLite (file based, no setup)

## Installation

1. Make sure Python 3.8+ is installed
2. Open the project folder in a terminal
3. Install the dependencies:
   ```
   pip install -r requirements.txt
   ```
4. Run the app:
   ```
   python app.py
   ```
5. Open `http://127.0.0.1:5000` in your browser

The SQLite database file `resumes.db` is created automatically the first time you run the app. If you already had a database from the older version of ResumeForge, the app will add the new columns (`template`, `photo`) automatically.

## How to Use

1. Pick a template from the dropdown at the top right (Modern / Classic / Minimal)
2. Optionally upload a profile photo (JPG/PNG, under 2MB)
3. Fill in your details on the left - the preview on the right updates as you type
4. For Experience and Education, put one entry per line. Lines that start with `-`, `*`, or `•` will become bullet points
5. Click **Save** to store it in the database
6. Click **Download PDF** to get a real PDF generated by the backend
7. Use the **Saved resumes** dropdown to load any resume you saved earlier - then **Update** or **Delete** as needed

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET    | `/api/resumes` | List all saved resumes (id, name, email, template, updated_at) |
| GET    | `/api/resumes/<id>` | Get one resume with all fields |
| POST   | `/api/resumes` | Create a new resume (JSON body) |
| PUT    | `/api/resumes/<id>` | Update an existing resume |
| DELETE | `/api/resumes/<id>` | Delete a resume |
| GET    | `/api/resumes/<id>/pdf` | Download the resume as PDF. Optional query: `?template=modern\|classic\|minimal` |

### Example - create a resume

```bash
curl -X POST http://127.0.0.1:5000/api/resumes \
     -H "Content-Type: application/json" \
     -d '{
           "name": "Jane Doe",
           "email": "jane@example.com",
           "phone": "+1 555 123 4567",
           "college": "State University",
           "summary": "Software engineer with 3 years of experience.",
           "skills": "Python, JavaScript, SQL",
           "experience": "Software Engineer at Acme (2022 - Now)\n- Built scalable services",
           "education": "B.Sc. CS, State University (2018 - 2022)",
           "template": "modern"
         }'
```

### Example - download PDF in classic template

```
GET /api/resumes/1/pdf?template=classic
```

## Notes

- Profile photos are stored as base64 data URLs in the database (so the DB can get bigger if you upload large images - keep them small)
- Skills should be comma separated
- Lines starting with `-`, `*`, or `•` in Experience/Education are rendered as bullet points
- The browser print button is still available if you prefer the browser PDF instead of the backend one
